## 第2页：问题 — 乡村教育的真实困境
- **数据说话**：
  - 中国乡村教师平均师生比 1:40+，远超城市 1:20
  - 乡村教师每周备课时间平均 12 小时，是城市的 1.5 倍
  - 67% 的乡村学校没有专职心理辅导老师
  - 留守儿童占比超过 40%，家庭教育缺位严重
- **三个痛点**：
  - 教师：备课负担重，因材施教难
  - 学生：学习问题无人及时解答，错题无人整理
  - 家长：想了解孩子学习情况，但看不懂、问不了

---

## 第3页：我们的方案
- **一句话**：一个纯前端的 AI 助教系统，教师、学生、家长三端协同
- **核心定位**：不是替代老师，而是让老师从重复劳动中解放出来
- **三个端口**：
  - 教师端：智能备课 + 学生画像 + 班级总览
  - 学生端：拍照答疑 + 针对性练习 + 错题本
  - 家长端：学情报告 + 教师建议 + 成长追踪

---

## 第4页：技术架构
- **极简架构**：纯前端 + 本地存储 + AI API
- **技术栈**：HTML/CSS/JS + ECharts + Qwen API + IndexedDB + Service Worker
- **部署零门槛**：一台普通电脑即可运行，无需服务器
- **离线可用**：Service Worker 缓存，断网也能用

## 第7页：乡村场景适配
- **离线能力**：Service Worker 缓存，教室断网也能用
- **低带宽优化**：纯前端架构，无需下载大型安装包
- **零部署成本**：打开浏览器就能用，不需要安装任何软件
- **数据安全**：所有数据存储在本地，不上传云端，保护学生隐私
- **大字体模式**：适配乡村老年教师
