# 部署与运维指南

> 适用版本：rural-ai-backend v0.1.0
> 本文档覆盖后端服务的部署、配置、日志、备份、测试与日常运维。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| Node.js | **>= 22**（依赖内置 `node:sqlite`，22.5+ 可用） |
| 操作系统 | Linux / macOS / Windows 均可 |
| 数据库 | 无需安装，使用内置 SQLite 单文件（`backend/data/rural-ai.db`） |

---

## 二、配置（.env）

首次部署前，将 `.env.example` 复制为 `.env` 并按需填写：

```bash
cd backend
cp .env.example .env
```

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 服务端口 | `3000` |
| `NODE_ENV` | `development` / `production` | `development` |
| `JWT_SECRET` | JWT 签名密钥（**生产必须设置**） | dev 默认值 |
| `FRONTEND_DIR` | 前端静态目录 | `backend` 上一级 |
| `LOG_DIR` | 日志目录 | `backend/logs` |
| `LOG_KEEP_DAYS` | 日志保留天数 | `7` |
| `RATE_LIMIT_WINDOW_MS` | 认证接口限流窗口（毫秒） | `60000` |
| `RATE_LIMIT_MAX` | 窗口内最大认证请求数 | `30` |

> ⚠️ **安全**：生产环境必须设置强 `JWT_SECRET`，否则服务会拒绝启动。
> 生成随机密钥：
> ```bash
> node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
> ```

## 三、启动方式

### 1. 直接运行（开发/演示）

```bash
cd backend
npm start            # node src/index.js
```

### 2. PM2（生产推荐，崩溃自动重启）

```bash
npm i -g pm2
pm2 start src/index.js --name rural-ai --env production
pm2 save
pm2 startup          # 设置开机自启
```

常用命令：`pm2 logs`、`pm2 restart rural-ai`、`pm2 monit`

### 3. systemd（Linux 服务化）

新建 `/etc/systemd/system/rural-ai.service`：

```ini
[Unit]
Description=Rural AI Tutor Backend
After=network.target

[Service]
WorkingDirectory=/path/to/backend
ExecStart=/usr/bin/node src/index.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production
Environment=JWT_SECRET=<你的强密钥>

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now rural-ai
```

> 服务支持**优雅停机**：收到 `SIGTERM`/`SIGINT` 时会停止接收新连接并安全关闭数据库。

## 四、健康检查

可用于负载均衡/容器编排探活：

```bash
curl http://localhost:3000/api/health
```

返回 `status: ok` 且 HTTP 200 表示正常；数据库异常时返回 `status: degraded` 与 HTTP 503。

---

## 五、日志

日志写入 `backend/logs/`（可用 `LOG_DIR` 覆盖），按日轮转、默认保留 7 天：

- `access-YYYY-MM-DD.log`：访问日志（健康检查请求不计入）
- `error-YYYY-MM-DD.log`：错误日志

排查问题：`tail -f backend/logs/error-*.log`

---

## 六、数据库备份与恢复

```bash
# 备份（写入 backend/backups/，默认保留最近 10 份）
npm run backup          # node scripts/backup-db.mjs

# 指定保留份数
node scripts/backup-db.mjs --keep 14

# 恢复
npm run restore -- backend/backups/rural-ai-2026-08-15T03-11-49.db
# 即：node scripts/backup-db.mjs --restore <备份文件>
```

> 建议配置定时任务（crontab）每日备份：
> ```
> 0 2 * * * cd /path/to/backend && node scripts/backup-db.mjs --keep 14 >> /var/log/rural-ai-backup.log 2>&1
> ```

## 七、测试

一键运行全部测试（自动启动服务、跑完优雅关闭）：

```bash
npm test
```

包含两套测试：
- `smoke-test.mjs`：三端接口与越权拦截（24 项）
- `frontend-sync-test.mjs`：三端同步 + 邀请码绑定 + 忘记密码（48 项）
