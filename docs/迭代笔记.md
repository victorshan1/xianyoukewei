### 测试命令（backend/ 下）
- `npm test` —— 单元 + 集成全部
- `npm run test:unit` —— 仅单元
- `npm run test:coverage` —— 覆盖率
- `npm run test:integration` —— 仅集成
- `npm run backup` / `npm run restore -- <文件>` —— 数据备份/恢复

### 越权覆盖（smoke-test 七）
- 跨角色：家长看他人孩子、学生录成绩、未登录 → 401/403
- 同角色隔离：学生 A 访问/修改/删除学生 B 的全类数据 → 403
- 反向隔离验证 + 隔离不误伤（访问自己的数据=200）
- 教师跨班越权 → 403

## 三、注意事项 / 已知事项

- 后端依赖 `node:sqlite`（Node 22.5+），`engines.node >= 22`。
- 生产环境必须设置 `JWT_SECRET` 强密钥，否则拒绝启动（见 `security.js`）。
- 数据备份目前存放服务器本地 `backend/backups/`，若要"防灾难"需扩展到异地/对象存储。
- 前端 IndexedDB 本地数据不在后端备份范围内。
- 跑集成测试时若 `express` 丢失，先 `npm install`。
