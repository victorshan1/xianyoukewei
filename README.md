# 乡村课堂AI助教平台

面向乡村教育的AI助教平台，融合「看见」学生数字画像系统 + 「小语智研」备课能力，三端口架构：教师端、学生端、家长端。

## 功能特性

### 教师端（P0优先级）
- **备课助手**：AI智能生成教案和分层作业（基础/提高/拓展三层）
- **学生画像**：五维雷达图展示、归因分析、个性化建议生成
- **班级学情总览**：统计数据、成绩分布图、学习趋势图、薄弱知识点分析
- **学生管理**：支持批量导入/导出学生数据

### 学生端（P1优先级）
- **拍照答疑**：拍照/上传题目图片，AI智能解析，支持语音输入
- **针对性练习**：基于学生画像推荐薄弱点专项训练，难度自适应

### 家长端（P2优先级）
- **学情报告**：周报/月报，可视化图表展示学习数据
- **家校沟通**：AI生成个性化沟通话术

## 技术架构

### 纯前端架构
- **无需后端服务器**：所有数据存储在浏览器本地（localStorage + IndexedDB）
- **低带宽友好**：适合乡村网络环境
- **跨设备兼容**：支持电脑和手机浏览器访问

### 技术栈
- HTML5 + CSS3 + Vanilla JavaScript
- IndexedDB 本地数据库
- localStorage 配置存储
- Qwen系列模型API（文本生成、视觉理解）
- Canvas数据可视化（雷达图、折线图、柱状图）
- 响应式设计（适配桌面和移动端）

## 部署说明

## 使用说明

### 首次使用配置

1. **配置API Key**
   - 点击右上角⚙️设置按钮
   - 输入Qwen API Key（从阿里云DashScope获取）
   - 可选择API Base URL和模型
   - 点击"测试连接"验证配置

2. **初始化示例数据**
   - 系统会自动填充10名示例学生和成绩数据
   - 可在设置页面清除数据后重新录入

### 教师端使用流程

1. **备课助手**
   - 选择学科、年级、课时
   - 输入课题名称
   - 点击"生成教学方案"
   - AI生成教案和分层作业
   - 可复制方案或打印为PDF

2. **学生画像**
   - 从左侧列表选择学生
   - 查看五维雷达图（知识掌握、学习习惯、思维能力、实践应用、进步趋势）
   - 查看归因分析（错误原因概率）
   - 点击"生成建议"获取个性化教学建议
   - 点击"录入成绩"添加新的成绩记录

3. **班级学情总览**
   - 选择班级和学科
   - 查看统计卡片（班级人数、平均分、及格率、优秀率）
   - 查看成绩分布图和学习趋势图
   - 分析薄弱知识点排行

4. **学生管理**
   - 点击"添加"按钮录入学生信息
   - 点击"导出"按钮导出学生数据为JSON文件
   - 点击"导入"按钮从JSON文件批量导入学生

### 学生端使用流程

1. **拍照答疑**
   - 点击上传区域选择题目图片（或点击"拍照"按钮）
   - 可选择语音输入补充说明
   - 点击"提交问题"
   - AI识别题目并给出详细解答步骤
   - 查看相关知识点标签

2. **针对性练习**
   - 选择学科、年级、难度
   - 可指定知识点或留空使用默认推荐
   - 点击"开始练习"
   - AI生成练习题（选择题/填空题）
   - 答题后点击"提交答案"
   - 查看正确率、用时、知识点分析

### 家长端使用流程

1. **学情报告**
   - 选择孩子（从学生列表）
   - 切换周报/月报
   - 查看学习时长、作业完成率、平均成绩
   - 查看成绩趋势图和学科表现柱状图
   - 阅读学习情况分析和教师建议

2. **家校沟通**
   - 选择沟通场景（询问作业、了解表现、沟通行为问题等）
   - 选择沟通对象（班主任、科任老师、校领导）
   - 输入具体内容（可选）
   - 点击"生成沟通话术"
   - AI生成个性化沟通话术
   - 可复制话术到剪贴板

## 数据管理

### 数据存储位置
- **localStorage**：API Key、当前端口、用户配置
- **IndexedDB**：学生信息、成绩数据、画像数据、教案记录、答疑记录、练习记录、学情报告

### 数据备份
1. 进入设置页面
2. 点击"导出数据"按钮
3. 系统生成JSON备份文件
4. 保存到安全位置

### 数据恢复
1. 进入设置页面
2. 点击"导入数据"按钮
3. 选择之前导出的JSON文件
4. 系统自动恢复所有数据

### 清除数据
1. 进入设置页面
2. 点击"清除所有数据"按钮
3. 确认两次后清除所有本地数据
4. 页面自动刷新

## API配置说明

### 获取Qwen API Key
1. 访问阿里云DashScope控制台：https://dashscope.console.aliyun.com/
2. 注册/登录阿里云账号
3. 开通DashScope服务
4. 创建API Key
5. 复制API Key到平台设置页面

### 支持的模型
- **qwen-max**：通义千问Max（推荐，功能最强）
- **qwen-plus**：通义千问Plus（轻量，性价比高）
- **qwen-turbo**：通义千问Turbo（快速响应）
- **qwen-vl-max**：通义千问VL Max（视觉理解，用于拍照答疑）
- **qwen-vl-plus**：通义千问VL Plus（视觉轻量）
- **deepseek-chat**：DeepSeek Chat（高性价比）
- **deepseek-reasoner**：DeepSeek Reasoner（深度推理）
- **自定义模型**：支持任意 OpenAI 兼容 API 的模型

### API调用说明
- 所有API调用均从浏览器直接发送到AI服务商
- API Key仅存储在本地浏览器，不会上传到任何服务器
- 支持阿里云通义千问、DeepSeek及任意OpenAI兼容API
- 建议定期更换API Key以保证安全
- 注意API调用额度，避免超额产生费用

### 多API支持
平台支持配置多种AI服务，在设置页面可切换：

| 服务商 | Base URL | 推荐模型 |
|--------|----------|----------|
| 阿里云通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-max |
| DeepSeek | `https://api.deepseek.com/v1` | deepseek-chat |
| 自定义 | 任意OpenAI兼容API地址 | 自定义 |

### 数据量管理
- 建议单个班级学生数量不超过50人
- 定期导出备份并清理历史数据
- 成绩记录建议保留最近一学期

### 网络优化
- API调用需要网络连接
- 建议在WiFi环境下使用
- 离线时可查看已缓存的数据

### 浏览器优化
- 清除浏览器缓存可能删除本地数据，请定期备份
- 建议使用专用浏览器或Chrome配置文件隔离数据
- 避免使用隐私模式/无痕模式

## 常见问题

### Q: 数据会丢失吗？
A: 数据存储在浏览器本地，清除浏览器数据、更换设备或浏览器会导致数据丢失。请定期使用"导出数据"功能备份。

### Q: 多个老师能共用数据吗？
A: 纯前端架构下，数据仅存储在单个浏览器中。如需多设备同步，需定期手动导入导出数据。

### Q: API调用有次数限制吗？
A: 取决于阿里云DashScope的配额政策。建议查看控制台配额说明，避免超额产生费用。

### Q: 可以在手机上使用吗？
A: 可以。在手机上访问部署地址，系统会自动适配移动端布局。建议使用Chrome或Safari浏览器。

### Q: 语音输入不工作？
A: 语音识别需要浏览器支持Speech Recognition API，并且需要麦克风权限。部分浏览器（如Firefox）可能不支持此功能。

### Q: 如何迁移到另一台电脑？
A: 在旧电脑上"导出数据"，将JSON文件复制到新电脑，在新电脑上"导入数据"。

## 开发说明

### 本地开发
```bash
# 启动开发服务器
python3 -m http.server 8080

# 访问 http://localhost:8080
```

### 代码结构
- 所有JavaScript使用IIFE模式避免全局污染
- 使用全局命名空间`window.App`组织模块
- 路由使用hash模式（`#/teacher/lesson-plan`）
- 页面通过fetch动态加载HTML模板

### 添加新功能
1. 在`js/pages/`创建新模块
2. 在`pages/`对应端口目录创建HTML模板
3. 在`js/router.js`添加路由配置
4. 在`index.html`侧边栏添加菜单项
