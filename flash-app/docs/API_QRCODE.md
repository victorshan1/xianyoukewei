# qrcode.react

开发环境中已经集成了 qrcode.react，如需使用 qrcode.react 组件，需要在对应的代码文件中引入，示例如下

```typescript
import { QRCodeCanvas } from 'qrcode.react';
<QRCodeCanvas value={value} size={size} />
```
