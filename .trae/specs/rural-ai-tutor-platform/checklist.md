# Checklist - 乡村课堂AI助教平台

## 基础架构验证

- [ ] 项目结构完整，包含HTML主入口、CSS样式、JavaScript模块（api.js、storage.js、router.js）
- [ ] 三端口导航结构正常工作（教师端、学生端、家长端可切换）
- [ ] 响应式布局正常，在电脑浏览器和手机浏览器上均可正常显示
- [ ] localStorage正确存储和读取配置数据（API Key、用户设置）
- [ ] IndexedDB正确存储和读取结构化数据（学生信息、成绩、作业记录）
- [ ] 数据持久化验证：刷新页面后数据不丢失
- [ ] Qwen API调用封装正确，支持文本生成和视觉理解
- [ ] API Key配置界面可正常保存和读取配置
- [ ] API调用状态管理正确（加载中、成功、失败、超时均有对应提示）

## 教师端验证（P0）

### 备课助手
- [ ] 备课助手界面包含学科、年级、课题输入表单
- [ ] 教案生成功能正常：输入信息后调用Qwen API生成符合课标的教案
- [ ] 生成的教案包含教学目标、重难点、教学过程、板书设计
- [ ] 分层作业生成功能正常：可选择基础/提高/拓展难度
- [ ] 生成的作业包含知识点标签和预计完成时间
- [ ] 教案可复制到剪贴板
- [ ] 教案可打印/导出为PDF

### 学生画像
- [ ] 学生列表页面正常展示所有学生，支持搜索功能
- [ ] 五维雷达图正常展示（知识掌握、学习习惯、思维能力、实践应用、进步趋势）
- [ ] 归因分析正常展示各维度错误原因概率
- [ ] 个性化建议生成功能正常（基于画像数据调用AI）
- [ ] 学生数据录入界面可正常录入作业/考试成绩
- [ ] 录入数据后学生画像自动更新，五维得分和归因概率重新计算

### 班级学情总览
- [ ] 班级总览界面展示统计卡片（平均分、及格率、优秀率）
- [ ] 趋势图正常展示（折线图展示成绩变化）
- [ ] 知识点掌握热力图正常展示（矩阵形式展示各知识点掌握情况）
- [ ] 重点关注学生名单自动识别并展示（成绩下滑/长期落后学生）

## 学生端验证（P1）

### 拍照答疑
- [ ] 拍照/上传界面正常，可调用摄像头拍照或从相册选择图片
- [ ] 图片上传后正确调用Qwen VL模型识别题目
- [ ] 解题步骤和答案正确展示（Markdown格式渲染）
- [ ] 知识点标签正确展示，可点击溯源
- [ ] 语音输入功能正常，可调用浏览器语音识别API转为文字

### 针对性练习
- [ ] 练习界面根据学生画像推荐薄弱知识点的题目
- [ ] 答题交互正常（支持选择/填空，可自动判题）
- [ ] 难度自适应逻辑正确（答对提升难度，答错降低难度）
- [ ] 练习结果展示正确（正确率、用时、知识点分析）
- [ ] 练习数据正确同步到学生画像，更新五维得分

## 家长端验证（P2）

### 学情报告
- [ ] 报告选择界面支持周报/月报切换
- [ ] 学习数据统计展示正确（图表：学习时长、作业完成、测验成绩）
- [ ] 趋势对比展示正确（本周vs上周对比）
- [ ] 薄弱知识点和改进建议正确展示

### 家校沟通
- [ ] 沟通场景选择界面正常展示（成绩下滑、了解表现等场景）
- [ ] AI话术生成功能正常（结合学生画像数据生成）
- [ ] 生成的话术可正常展示和复制

## 集成与数据同步验证

- [ ] 教师端完整流程测试通过：备课→录入成绩→查看画像→班级总览
- [ ] 学生端完整流程测试通过：拍照答疑→练习→数据更新
- [ ] 家长端完整流程测试通过：查看报告→生成沟通话术
- [ ] 数据同步测试通过：教师录入成绩→学生画像更新→家长报告更新
- [ ] 页面加载速度 < 3秒（首次加载后）
- [ ] 移动端交互体验流畅（触摸交互正常，无明显卡顿）
- [ ] 加载状态和错误提示正确展示
- [ ] 数据导入/导出功能正常（可备份和恢复数据）

## 技术约束验证

- [ ] 纯前端实现，无需后端服务即可运行所有功能
- [ ] 可在普通教学电脑上正常运行（Chrome/Firefox/Edge浏览器）
- [ ] 可在老师手机上正常运行（移动端浏览器）
- [ ] 所有数据存储在本地（localStorage/IndexedDB），无网络请求时仍可使用基础功能
- [ ] Qwen API调用失败时有降级方案（提示用户，不影响其他功能）
